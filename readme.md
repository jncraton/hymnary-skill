An agent skill to provide Hymnary recommendations

[hymnary.skill](https://jncraton.github.io/hymnary-skill/hymnary.skill)

## Installation

### Claude

1. Download [hymnary.skill](https://jncraton.github.io/hymnary-skill/hymnary.skill)
2. Upload the skill to claude.ai
  1. Select `Customize`
  2. Select `Skills`
  3. In the `Add Skill` menu, expand `Create Skill` and select `Upload a skill`
3. Prompt a new chat for hymn recommendations, and the skill should activate
